# 发布后人工测试清单

本清单只包含无法在当前 Windows 自动化环境完成的项。所有项目必须在真实设备上执行，禁止使用截图或录屏做视觉断言，按 DOM/日志/系统状态记录结果。

## macOS arm64（发布后）

### 安装与启动

- [ ] 从 DMG 安装到 `/Applications`。
- [ ] 首次打开：右键 → 打开，确认 Gatekeeper 提示与预期一致。
- [ ] 菜单栏图标显示；Dock 不显示图标（ActivationPolicy::Accessory）。
- [ ] 悬浮球透明、置顶、不占 Dock；展开为 360×600。
- [ ] 贴右/下边展开方向正确；Retina 1x/2x 混合屏幕定位正确。

### 权限与径向菜单

- [ ] 首次长按 Mouse4 时提示授权“辅助功能”。
- [ ] 跳转系统设置 → 隐私与安全性 → 辅助功能，授权后轮询检测生效。
- [ ] 未授权时面板显示明确提示，不静默失败。
- [ ] 长按 Mouse4 250ms 出现 8 扇区覆盖层；短按保留原点击。
- [ ] 覆盖层不抢焦点、不处理 DOM 鼠标事件。
- [ ] 中心取消；松手按角度选择正确。
- [ ] 双屏/负坐标下覆盖层不越出工作区。

### 生物识别与安全

- [ ] Touch ID 可用时提示；取消/失败回退主密码。
- [ ] 设置页将 Touch ID 标记为“实验性”。
- [ ] 重装/重新签名后钥匙串授权失效时，能捕获失败并回退。
- [ ] 系统锁屏/休眠后返回需要重新解锁。
- [ ] 闲置锁定按 5/15/30/60 分钟触发。

### 更新

- [ ] 更新检查能从 `latest.json` 读取版本与 notes。
- [ ] 下载进度、安装、重启成功。
- [ ] 更新后首次启动弹一次“本次更新内容”，标记已读后不再弹。
- [ ] 未签名替换后 Touch ID 行为记录（预期可能失效）。

## Windows 真机补充

- [ ] Windows Hello：用真实 PIN/指纹完成一次 `security_unlock_biometric`。
- [ ] Windows Hello 取消/失败回退主密码。
- [ ] 系统锁屏 → 解锁回桌面，KeyDock 仍处于锁定状态（WTS 已验证一次，复测）。
- [ ] 休眠/唤醒后 KeyDock 锁定。
- [ ] 托盘菜单：显示/隐藏、锁定、退出。
- [ ] 全局快捷键 Ctrl+Shift+K / Ctrl+Shift+L 在应用失焦时触发。
- [ ] 快捷键冲突（例如被其他软件占用）时提示，原组合不被破坏。
- [ ] 悬浮球拖动不吞点击；贴边时面板翻向正确。
- [ ] 覆盖层在多显示器 + 混合 DPI 下的实际视觉位置（用窗口矩形与鼠标坐标断言，不截图）。
- [ ] 360 / QQ 浏览器：探测到但调试端口不可用时给出明确提示。
- [ ] 强杀 KeyDock 后重启：残留 Profile 被清扫；Chrome 未残留（Job Object）。
- [ ] NSIS 安装、升级、卸载（本地构建已完成；静默安装在锁屏会话中未能完成）。
- [ ] 安全软件开启时 WH_MOUSE_LL 是否仍工作；快捷键是否作为等价入口。

## 登录与验证码

- [ ] 同域登录成功判定。
- [ ] 跨域 SSO 成功判定；密码错误不被误判。
- [ ] iframe 内表单填充（跨域）。
- [ ] 下载文件落到系统下载目录、文件名正确、`download:done` 提示。
- [ ] 验证码 OCR 成功、失败转人工、刷新重试三条路径。
- [ ] 目标站点采集 50–100 张验证码离线对拍；低于 80% 时按站点微调模型。
- [ ] 选择器学习全程不产生任何含密码的日志或文件（检查 `%APPDATA%\com.xsjie.keydock` 与日志）。
- [ ] 书签关键词为空时不过滤；白名单添加/删除生效。
- [ ] 配置导出/导入（不含 vault）在换机场景可用。
