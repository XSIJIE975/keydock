# ADR 0003: 凭据库与运行时清理

- 状态：Accepted
- 日期：2026-10-20

## 凭据库

- scrypt 参数固定在配置信封中（`log_n=14, r=8, p=1, keylen=32`），便于未来升级时读取旧文件。
- AES-256-GCM 使用 12 字节随机 nonce；AAD 固定为 `keydock-vault-v1`，防止信封字段被跨版本拼接。
- 密文包含 GCM tag；外层是 JSON 信封而不是二进制。
- 原子写：`vault.enc.tmp` → fsync → rename；失败重试一次以应对杀毒软件短暂占用。
- 派生密钥仅在用户显式开启快速解锁后写入系统钥匙串；主密码与密钥不落盘。
- 修改主密码会生成新 salt 与新 key，整体重封；旧密码立即失效。
- 错误密码延迟由 UI 层状态机维护（1/2/4/8 秒封顶），不改变 KDF 参数。

## 运行时清理

- 每个浏览器会话使用独立临时 Profile。
- Windows 使用 Job Object `KILL_ON_JOB_CLOSE`；应用崩溃时浏览器随 Job 终止。
  - 若进程已在其他 Job 中（IDE/CI），分配可能失败并记录警告；正常关闭路径仍会清理。
- 关闭顺序固定为 CDP `Browser.close` → 等待进程退出 → 删除 Profile。
- 应用启动时扫描并删除 `.tmp/sessions` 下的会话目录；单实例锁保证此时没有存活会话。
- 应用退出时取消所有会话，等待最多 3 秒。

## 安全不变量对应

| 不变量 | 实现 |
|---|---|
| I1 config 无密码明文 | 固定验证码是唯一允许写入配置的值；账号密码只写 vault |
| I2 ciphertext 为密文 | AES-256-GCM + AAD；单测检查明文不出现 |
| I3 明文不跨进程 | 仅 `shared_get` 返回明文；账号密码留在 Rust 进程 |
| I4 不写日志 | 登录/学习日志只包含阶段、站点名、错误分类；不记录表单值 |
| I5 临时 Profile 清除 | 关闭删除 + 启动清扫 |
| I6 主密码/密钥不落盘 | 主密码不存；派生密钥仅系统钥匙串 |
| I7 不写 Login Data | 不调用浏览器密码保存/自动填充接口；独立 Profile |
| I8 不保留会话快照 | 会话结束后删除 Profile，不保存页面内容 |
